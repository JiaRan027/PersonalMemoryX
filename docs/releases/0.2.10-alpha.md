## 中文

这是 PersonalMemory 的 Windows x64 Alpha。它把用户自己控制的本地记忆，通过受治理的 MCP 上下文与选择性 Hook 接入 Claude Code 和 Codex，目标是让不同 Agent 能延续已确认的背景，而不是保存全部聊天记录。

### 开始使用

1. 下载 `PersonalMemory_0.2.10_x64-setup.exe` 并运行。安装仅作用于当前 Windows 用户。
2. 启动 PersonalMemory，打开“接入”，按需连接 Claude Code 或 Codex。
3. 在 Codex Desktop 的“设置 → Hooks”审核 PersonalMemory 的用户级 `UserPromptSubmit` 和 `Stop` Hook；在 Claude Code 中按接入页提示创建新会话。
4. 打开一个新的 Agent 会话，提问一项你之前真实表达过、适合长期保留的信息；在 PersonalMemory 中检查来源、证据和治理状态。
5. 再在另一个新会话自然询问相关内容，并确认 Agent 确实调用了 PersonalMemory 的读取工具。

自动记录是选择性的，不是聊天存档。配置存在或 Hook 已审核都不等于 Hook 已实际送达；请以接入页最近到达时间和活动记录为准。未经真实现场验证的 Codex Hook 回执与跨 Agent 召回不作为已验收能力宣称。

## English

This is the Windows x64 Alpha of PersonalMemory. It keeps a user-controlled local Memory Core and exposes governed context through MCP and selective Hooks for Claude Code and Codex. The goal is continuity across agents, not a complete archive of every chat.

### Get started

1. Download `PersonalMemory_0.2.10_x64-setup.exe` from the Release assets and run it. Installation is per Windows user.
2. Open PersonalMemory, go to **Connections**, and connect Claude Code or Codex as needed.
3. In Codex Desktop, review the PersonalMemory user-level `UserPromptSubmit` and `Stop` Hooks under **Settings → Hooks**. In Claude Code, follow the Connections page and start a new session.
4. In a new agent session, mention one genuine, durable fact you have previously stated. Inspect its source, evidence, and governance state in PersonalMemory.
5. Ask about it naturally in another new session and confirm that the agent actually used a PersonalMemory retrieval tool.

Automatic capture is selective; it is not a transcript archive. A configured or approved Hook is not proof of delivery. Use the latest Hook receipt and activity record as evidence. Real-world Codex Hook receipts and fresh-session cross-agent recall are not claimed as verified in this release.

## Release trust and compatibility

- Installer SHA-256: `4f29939b4e2ffe9b66a1ba005f869b7fbfbf5d799ea58cf1778ba396d16e20d6` (`PersonalMemory_0.2.10_x64-setup.exe.sha256`).
- The Windows updater verifies Tauri's Minisign signature using the public key pinned in the application. `.sig` is an update-package signature, not Windows Authenticode and not a SmartScreen publisher identity.
- The installer is not Authenticode-signed; Windows may show an unknown-publisher warning.
- The `.sha256` file detects package mismatch/corruption when compared with a trusted release copy; it is not a publisher signature.
- The installer bundles unmodified Visual C++ runtime DLLs copied from Visual Studio 2026 Community's `VC\Redist\MSVC\14.51.36231\x64\Microsoft.VC145.CRT`; each packaged copy was SHA-256 checked. Microsoft's redistribution terms require a valid license and permitted use context. This technical verification is not a legal opinion.
- Supported systems: Windows 10/11 x64. The installer preserves the app's existing user data directory, but back up valuable data before upgrading.
- PersonalMemory remains Alpha. Automatic memory capture can miss useful information and may need review; do not rely on it as the sole record of critical information.
- Real-world Codex Hook receipts, cross-agent recall in a fresh task, live update installation, and failure rollback have not been verified in this release turn.
